# Gametoemployee

A gamified hiring test built as a React frontend with a .NET backend.

## Scenario

The application simulates work on a PIM (Product Information Management) system. Candidates receive:

- requirements for the sprint
- a maintenance support inbox with incoming tickets
- mapped full-stack issues to resolve
- skill ratings that show how far they progress in the game
- achievements unlocked by completing meaningful milestones

## Run locally

### Backend

```bash
cd /home/runner/work/Gametoemployee/Gametoemployee/backend
dotnet run
```

### Frontend

```bash
cd /home/runner/work/Gametoemployee/Gametoemployee/frontend
npm install
npm run dev
```
